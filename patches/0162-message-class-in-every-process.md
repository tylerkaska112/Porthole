# 0162 win32u: register the "Message" window class in every pseudo-process

`vendor/Madeira/build/win32u-unix/class_ios.c`, `register_builtins` (run once per pseudo-process by `register_builtin_classes`): also `register_builtin( &message_builtin_class )`, and a `[builtin-classes] 0162 the Message class registered for pid=...` log line.

Reason (Counter-Strike 2, 2026-10-18, builds 1.1.43-1.1.46): first-person look stopped at a fixed angle in every control layout. Patch 0158 showed no raw mouse device is ever registered (`raw-mouse processes=0`), 0159/0161 showed why: the game's SDL3 `SDLRawInput` thread creates a message-only window of class `'Message'` (parent = the message window, class-instance 0) and `create_window_handle` fails with last error 6 (STATUS_INVALID_HANDLE) at once; the thread then exits before `RegisterRawInputDevices`. 0160 (a thread with no usable desktop) never triggered, so it was not that. The cause is in `class_ios.c`: `init_user` -> `register_desktop_class()` registers the desktop and `Message` classes only in the session's FIRST pseudo-process (a `pthread_once`); `register_builtin_classes` was already made per-process for the Button/Static/... classes (Steam's update UI) but not for `Message`; `ios_child_desktop_fixup` (winstation_ios.c) registers the pair only when `get_desktop_window` fails in a child. The wineserver keeps classes per process, so in a later process (the game, started by Valve's client) `grab_class` finds no `Message` class and fails. Portal 2 logged the same single failure harmlessly.

Effect: a later process can create message-only windows of class Message (SDL's raw-input thread; other programs' message windows), so SDL registers raw mouse input and a game that reads raw movement is no longer limited by the pointer position. Changes how games run (engine bump). In the session's first process the registration is a repeat; the server refuses the duplicate and `register_builtin` tolerates it.

Build: `tools/rebuild_win32u_ws_object.sh win32u:class_ios:class` into `gl-lib-0162` (copy of `gl-lib-0161`), `LIB_OVERRIDES=<dir> tools/stage_runtime.sh`.
